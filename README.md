Sistema de Controle de Estoque e Precificação Dinâmica

Cliente: Júnior (Geek Store)

Objetivo do Sistema: 
Gerenciar o estoque de colecionáveis e action figures aplicando regras automatizadas de precificação baseadas na escassez do produto. Quando resta apenas uma unidade no estoque, o sistema adiciona uma tag visual de destaque e aplica um acréscimo automático de 10% sobre o preço base.
